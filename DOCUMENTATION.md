# Personal Portfolio Website - Documentation

## 1. Project Title

Personal Portfolio Website

---

## 2. Project Overview

The Personal Portfolio Website is a responsive website designed to present personal information, skills, projects, education, and contact details in a simple and professional format.

The website provides an easy way for visitors to learn about the developer and their technical interests.

---

## 3. Project Objective

The main objective of this project is to create a personal portfolio website while gaining practical experience in:

- HTML5
- CSS3
- Flexbox
- Responsive web design
- Website layout
- Navigation
- Basic UI design

---

## 4. Technologies Used

- HTML5
- CSS3
- Visual Studio Code
- Git
- GitHub

---

## 5. Main Features

### 5.1 Home Section

Introduces the developer and provides quick navigation to projects and contact information.

### 5.2 About Section

Provides information about education, interests, and areas of development.

### 5.3 Skills Section

Displays technical skills and technologies.

### 5.4 Projects Section

Displays projects with their descriptions and technologies used.

### 5.5 Contact Section

Provides contact information and an email option.

### 5.6 Responsive Design

The website adapts its layout for smaller screen sizes using CSS media queries.
